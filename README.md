# Prep for Internship/Placement:

This repository contains a collection of PDF notes and resources for computer science concepts, algorithm preparation, and interview readiness which I used for intern prep. Hope that these become useful for placement prep(algos + cpp) as well.

**I used C++ as the reference programming language..**

## 📚 Contents

- **Cpp prep.pdf**: C++ programming preparation notes.
- **SQL Notes.pdf**: SQL basics for OAs and intervews.
- **DSA-CLRS notes.pdf**: Notes based on the classic *Introduction to Algorithms* (CLRS) book.
- **Leetcode common questions.pdf**: A curated list of common LeetCode problems.
- **ML_notes.pdf**: Machine Learning concepts and notes.
- **Trick questions.pdf**: Common trick questions encountered in interviews.
- **data structure.pdf**: General notes on Data Structures.
- **dynamic programming.pdf**: Concepts and problems related to Dynamic Programming.
- **graphs.pdf**: Notes covering Graph algorithms and structures.
- **math.pdf**: Mathematical concepts relevant for competitive programming and interviews.
- **ml_interview_questions.pdf**: Specific questions for Machine Learning interviews.
- **recursion.pdf**: Notes on Recursion principles and problems.

## 🚀 How to use
Feel free to download and read through these PDFs to prepare for technical interviews.
